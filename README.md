# Competitive Programming — Algorithms & Data Structures

## Descripción

Este repositorio tiene como objetivo almacenar y organizar algoritmos y estructuras de datos dedicados a la **programación competitiva**.

Su contenido está organizado por temas, facilitando la consulta, el estudio y la reutilización de las distintas implementaciones.

## Organización

Los algoritmos y estructuras de datos se agrupan en directorios según su temática.

Esta organización permite localizar fácilmente las implementaciones relacionadas con un tema concreto y mantener el repositorio estructurado a medida que crece su contenido.

## Objetivo

Disponer de una colección organizada de algoritmos y estructuras de datos que sirva como recurso de consulta y apoyo para la programación competitiva.
